## Maintenance Rule

ISC2 updates the CISSP exam outline periodically (most recently effective **April 15, 2024**). Domain names, weights, question counts, and format can change between revisions. Before relying on any specific number in this repository for exam-day decisions, cross-check it against the live [CISSP Certification Exam Outline](https://www.isc2.org/certifications/cissp/cissp-certification-exam-outline).
